BUILT FOR THE DESKTOP

More than a looping video.

LiveWall provides the browser host features sophisticated web wallpapers expect, while staying a small native menu-bar app.

ICON-FRIENDLY

Widgets without losing your desktop.

Widget Mode keeps Finder icons visible. Clocks, calendars, and dashboards run beneath them; hold Option only when you need the wallpaper’s controls.

Wallpaper

CUSTOMIZE

Every property, in one native editor.

Change switches, sliders, colors, text, files, and presets live. Settings are remembered separately for each wallpaper.

AUDIO + MEDIA

Let the desktop hear what you hear.

Feed a 128-band system-audio spectrum to visualizers, plus now-playing metadata from Music and Spotify.

CONTROLLED ACCESS

Online only when you say so.

Remote requests are blocked by default. Grant internet access per wallpaper when a trusted weather or data widget needs it.

NATIVE MACOS

Small, quiet, and built for every Space.

One native wallpaper window per display, seamless video loops, fullscreen pausing, and optional battery-aware playback.

COMPATIBILITY

Bring the wallpapers you already own.

Paste an individual Steam Workshop link. LiveWall opens Valve’s SteamCMD for authentication, then imports the downloaded project from your local Steam library.

LiveWall is not affiliated with Valve or Wallpaper Engine. Workshop support is for content legitimately accessible through your own Steam account. No assets are bundled, decrypted, or redistributed.

LOCAL BY DESIGN

Your wallpaper does not need the keys to your Mac.

Web projects run in ephemeral WebKit storage with navigation confined to their project folder. Local file properties become data URLs, and sensitive capabilities remain visibly opt-in.
